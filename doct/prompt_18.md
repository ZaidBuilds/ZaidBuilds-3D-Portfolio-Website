# Prompt 18: Line-By-Line Explanation Mode

**What it does**: Forces the AI to break down complex code literally line by line.

**When to use**: When you run into a confusing block of code and need to understand the fundamental concepts and mechanics behind it.

---

Copy this into Copilot Chat:

Explain this code line by line.

For each line:
- What does it do?
- Why is it needed?
- What would break if we removed it?
- What concept does it represent?
- What category does it belong to? (routing, state management, API handling, etc.)

Explain it as if teaching a beginner becoming an engineer.
