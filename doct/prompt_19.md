# Prompt 19: Building Project Step-by-Step

**What it does**: Instructs the AI to act as a senior architect to plan everything out before actually coding.

**When to use**: At the very beginning of a new project or a massive new feature module.

---

Copy this into Copilot Chat:

We are going to build a project together step by step.

Before writing code, act like a senior software architect and explain the plan first.

1. Understand the project goal clearly:
    - What problem are we solving?
    - Who is the user?
    - What are the main features?
2. Propose a suitable tech stack:
    - Frontend
    - Backend
    - Database
    - Tools and libraries
    For each tool explain:
    - What it is
    - Why we use it
    - What problem it solves
    - Alternatives and tradeoffs
3. Explain the full system architecture:
    - How frontend connects to backend
    - How backend connects to database
    - Data flow from user action to response
4. Break the project into clear building phases:
    - Setup
    - Core features
    - API layer
    - UI integration
    - Testing
    - Deployment
5. When writing code:
    - Write step by step (do NOT dump everything at once).
    - Explain concepts simply.
    - Add meaningful comments in code.
    - Explain how each part fits into the bigger system.
6. My goal is deep understanding, not fast completion.
Assume I am learning architecture while building.
