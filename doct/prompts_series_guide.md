# 🚀 The Ultimate Learning & Development Prompt Series

Use these prompts in order to act as a senior mentor throughout your software engineering journey. Whether you are learning a new codebase or building a project from scratch, this logical series guarantees a deep understanding.

## Phase 1: Planning & Setup (Building Mode)
*Use these when starting a brand new project or module.*

- **[Prompt 19](prompt_19.md) - Building Project Step-by-Step**: Starts the planning phase. The AI acts as a senior architect mapping out features, tech stack, and building phases without writing code yet.
- **[Prompt 16](prompt_16.md) - Deep Explanation of Project**: Establishes the rule for the whole project to explain the "what", "why", "how", and "alternatives" behind every tool and library as you begin coding.
- **[Prompt 17](prompt_17.md) - System Architecture Request**: Once basic scaffolding is done, use this to map out the mental model of client, server, database, scaling, and deployment.

## Phase 2: Understanding an Existing Codebase
*Use these when studying clone projects or taking over an existing codebase.*

- **[Prompt 1](prompt_1.md) - Project Overview**: Gets the simple 1-sentence overview, business logic, user workflow, and core features.
- **[Prompt 2](prompt_2.md) - Dependencies & Libraries Explained**: Breaks down `requirements.txt` or `package.json` to explain every dependency's purpose.
- **[Prompt 14](prompt_14.md) - System Design Overview**: Higher-level breakdown of microservices vs monolith, DB design, scaling, and APIs.
- **[Prompt 3](prompt_3.md) - Data Flow & Architecture**: Maps out exactly how data gets from A to B within the system.

## Phase 3: Module & File Deep Dives
*Use these to understand how specific files manage state and logic.*

- **[Prompt 4](prompt_4.md) - App.py Detailed Breakdown**: Line-by-line breakdown of the entry-point file.
- **[Prompt 7](prompt_7.md) - Config.py - Constants Explained**: Explains the central configuration and why hard-coding is avoided.
- **[Prompt 11](prompt_11.md) - Dashboard UI - Components**: Explains the frontend library, page layouts, components, and state reactivity.
- **[Prompt 5](prompt_5.md) - Utils.py - Helper Functions**: Breaks down inputs, outputs, and purposes for helper logic.

## Phase 4: Feature-Specific Investigations
*Use these when you want to know how a single feature works end-to-end.*

- **[Prompt 8](prompt_8.md) - Feature Walkthrough - Step by Step**: Traces user clicks down to database changes.
- **[Prompt 9](prompt_9.md) - PDF Parsing Deep Dive**: Specific to ingestion/extraction APIs.
- **[Prompt 10](prompt_10.md) - Subscription/Core Logic Detection**: Explains core business algorithms (AI logic, rule sets).
- **[Prompt 12](prompt_12.md) - Cancellation Guides System**: Maps out domain-specific data structures.
- **[Prompt 13](prompt_13.md) - Analytics & Statistics**: Shows how mathematical formulas and aggregations are rendered.

## Phase 5: Debugging & Code Comprehension
*Use these when you hit a wall and cannot read a block of code.*

- **[Prompt 6](prompt_6.md) - AI Integration Deep Dive**: Explains complex API calls, prompt syntax, error handling, and formatting.
- **[Prompt 18](prompt_18.md) - Line-By-Line Explanation Mode**: Used for isolated, complicated blocks. Demands explanations down to the single line of logic.

## Phase 6: Final Review 
*Use this when you feel you are finished learning.*

- **[Prompt 15](prompt_15.md) - Complete Learning Path**: The AI tests YOU on the architecture, workflows, edge cases, improvements, and system principles.
